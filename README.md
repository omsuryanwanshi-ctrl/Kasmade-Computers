# KASMADE DATA CORPORATION – Multi Brand Store Website

Official business web application for **KASMADE DATA CORPORATION** (Brand: *KDC – Multi Brand Store*), established in 2012 in Deola, Nashik, Maharashtra.

> **Tagline:** “SATISFACTION IS OUR MOTTO”  
> **Secondary Tagline:** “Your Trust, Our Service... Always!”

---

## 🌟 Overview & Features

- **Multi-Brand Product Catalog**: Laptops, Desktops, Computer Components, CCTV & Surveillance, Printers, Networking, Peripherals, and Software.
- **Dedicated CCTV & Surveillance Section**: Outdoor bullet cameras, dome cameras, 360° Wi-Fi PTZ cameras, 4G SIM solar cameras, DVRs/NVRs, and surveillance hard drives.
- **Direct Quotation & WhatsApp Integration**: 1-click quotation requests with pre-filled WhatsApp messaging.
- **Technical Services & AMC**: Chip-level repairs, hardware upgrades, OS setup, network cabling, printer service, and institutional Annual Maintenance Contracts.
- **Admin Management Portal** (Passcode protected):
  - Add / edit / delete products from live inventory.
  - Upload product photos directly from computer or via image URL with live thumbnail previews.
  - Customize website banner backgrounds (Hero, Services, Promo banners) directly in the UI.
  - Track customer quotation enquiries with status workflow (`pending` / `contacted` / `completed`).
  - Edit store contact details and taglines.
- **Modern Responsive Design**: Dark Navy Blue (`#0B1528`) + Metallic Gold (`#D4AF37`) palette with glassmorphism overlays and technology-themed backgrounds.
- **Local SEO & Schema Markup**: Complete LocalBusiness structured data, Open Graph meta tags, and Google Maps integration.

## 🚀 Getting Started

### Prerequisites
- Node.js (v18 or higher)
- npm or yarn

### Installation

```bash
# Clone the repository
git clone https://github.com/omsuryanwanshi-ctrl/Kasmade-Computers.git

# Navigate to project directory
cd Kasmade-Computers

# Install dependencies
npm install

# Start development server
npm run dev
```

The site will be running on `http://localhost:3000/`.

### Build for Production

```bash
npm run build
```

The compiled output will be generated in the `dist/` directory.
